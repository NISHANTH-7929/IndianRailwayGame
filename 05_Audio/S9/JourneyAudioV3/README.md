# Journey audio V3

Original synthetic supplements, CC0-1.0; no external samples or authentic
WAP-7 recording claim. Existing approved Indian railway rolling, station and
horn recordings are retained separately under their original licenses.

Three continuous textures now run for 16 seconds. The motor mix reduces the
dominant hum and adds a quieter upper layer. A short loop-boundary correction
avoids an isolated discontinuity without a full-volume dip. Brake release and
emergency clips remain one-shot envelopes. Deterministic generation and PCM
measurements are recorded in manifest.json; runtime gain follows actual speed,
traction, curvature and brake application. Acoustic fidelity still requires
licensed prototype recordings and listening comparison.
