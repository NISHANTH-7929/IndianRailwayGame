# Locomotive modeling references

These files are visual research references, outside Unreal Content. They are not
texture maps, source meshes, or files to ship with the game.

| Local file | Source | Use |
|---|---|---|
| WAP7_Fab_reference.jpg | https://www.fab.com/listings/52320f50-6b09-4c6d-912a-f5df8ee70712 | User-selected appearance target; Poly Valley Studio preview. No marketplace mesh or texture package acquired. |
| WAP7_cab_reference.jpg | https://irfca.org/gallery/Locos/Electric/wap5_7/insidewap7/IMG_0092.JPG.html | Cab layout reference from IRFCA. Image reuse rights have not been granted for game distribution. |

The locomotive meshes and material values are authored by the local Blender
generator scripts. Reference image pixels are not embedded in the game assets.
Each generator and its exports remain editable. Dimensions and individual cab
variant details need review against the chosen locomotive before final acceptance.
